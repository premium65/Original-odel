THE PREMIUM MANAGEMENT SYSTEM EXPLAINED
===============================================================================

What it does:
Allows admins to assign premium hotel booking tasks to users. When users
complete these tasks, they earn commission fees added to their wallet.

How it works:
1. Admin selects a user from the user list
2. Admin enters hotel price to filter available hotels
3. Admin selects a hotel and sets commission percentage
4. Admin assigns a task number (1-30)
5. System creates premium task for the user
6. User completes the task
7. Commission is calculated and added to user's wallet

Commission Calculation:
Commission = (Percentage × Hotel Price) / 100

Example:
- Hotel Price: $1000
- Commission: 5%
- User Earns: $50

KEY INFORMATION AT A GLANCE
===============================================================================

User Tiers:
├─ TRIAL: Cannot receive premium tasks from admin
├─ GOLD: Full premium task access
└─ DIAMOND: Premium tier with full access

Validation Rules:
├─ Hotel Price: Must be > 0
├─ Commission: Must be ≥ 1%
├─ Task Number: Must be 1-30
├─ User Badge: Cannot be "trial"
└─ User Balance: Must maintain ≥ 10,000

Admin Panel Pages:
├─ /premium-list - View active premium tasks
├─ /premium-history - View all tasks (history)
└─ Add Premium Booking - Assign tasks (from user list)

Technology Stack:
├─ Backend: Node.js + Express + MongoDB
├─ Admin Panel: Next.js 14 + TypeScript + Mantine UI
└─ User Panel: Next.js 14 + TypeScript + NextUI

Key Files:
├─ Backend: /api-main/controllers/package.controller.js
├─ Models: /api-main/models/premiumTask.js
├─ Calculations: /api-main/lib/calculation.js
├─ Admin Form: /admin-panel-main/components/defaults/PreBookingAddForm/
└─ Config: /api-main/config/index.js
